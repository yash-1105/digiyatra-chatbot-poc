# Product

## Platform

web

## Product Purpose

An independent Digi Yatra information portal and bilingual AI assistant, with an authenticated administration interface. Preserve the existing Next.js routes, approved informational content, links, chatbot behavior and analytics.

## Capabilities and Constraints

This release changes frontend presentation only. API contracts, providers, retrieval, authentication/session checks, feedback and analytics behavior are unchanged. No backend, Railway, billing, credential or database changes are authorized for this redesign.

## Brand Commitments

The user's three official-site screenshots and https://digiyatrafoundation.com/ are the visual authority for the replacement design. This portal must retain a clear independent identity and must not claim endorsement. Permission for official trademark asset use remains an open decision; public availability alone is not permission. Do not invent airport counts or statistics.

## Accessibility & Inclusion

Preserve English/Hindi controls, text sizing, high contrast, keyboard navigation, screen-reader labels, reduced-motion support and responsive layouts.
